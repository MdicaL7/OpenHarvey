# 人工逐步测试手册

先审查本手册和条款对照表，再批准固定版本。当前真实实验未执行。

## 准备

使用已绑定合同记忆的企业管理员作为 owner，另准备同企业普通 member 测试账号。每轮新建团队；不要复用既有团队的记忆。选择配置的 TencentDB Memory 业务模型。

浏览器进入 /spaces 和 /experience。每份合同新建空间，事件作为对应空间附件。每次上传后实际发出读取指令；等消息完成和记忆整理完成两个状态。L1 用只读快照辅助检查。

候选须按种类、主题与真实来源选择；若找不到或找到多条，先记录失败／待处理，不用金标手动创建来补齐。确认记忆与合同业务审批分别记录。
