## 为什么没有直接打包公开真实合同

- PEAT-LLM4LCR：公开仓库有中文合同材料，但审批记忆链不匹配，脱敏并不完整；仓库MIT不能替代对各原始合同的隐私和权利核验。没有纳入其合同原件
  https://github.com/Hongbin-Xiao/PEAT-LLM4LCR
- ProvBench：法律条款与法条推荐任务，不是跨合同审批记忆数据；研究时论文链接的代码仓库不可用
  https://aclanthology.org/2025.acl-long.312/
- Bi-FLEET：合同实体/要素研究数据需申请，未取得可供本包再分发的原始数据
  https://github.com/WZH-NLP/Bi-FLEET
- ACORD：英语条款检索数据，任务、语言及审批记录结构不匹配；没有复制其数据
  https://github.com/The-Atticus-Project/acord
- LongMemEval：用于启发时间更新、知识修订与拒答的测试维度，没有复制其问题或用户记忆内容
  https://github.com/xiaowu0162/LongMemEval

这是一轮“未找到精确匹配”的研究结论，不是证明全球不存在相关数据集。公开页面可用性、许可和仓库内容之后可能变化。
