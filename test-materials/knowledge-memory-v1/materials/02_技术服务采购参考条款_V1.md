# 技术服务采购参考条款包 V1.0

编号：CY-TPL-2026-004；性质：参考范本，不是审查标准；维护部门：法务部；更新日：2026-07-15。
适用：数据看板与报表开发项目；选择条款时需结合合同范围填写方括号内容。

> 全部内容为虚构测试材料，不构成真实合同范本或法律建议。

## 条款一：付款（起草参考）
合同生效后，乙方提交等额合规发票及项目计划，甲方支付总价的20%；原型验收通过后支付30%；最终验收通过且收到剩余合规发票后30个自然日内支付50%。

## 条款二：验收（优先文本）
乙方按附件交付清单提交成果及测试报告。甲方在10个工作日内提出书面反馈。甲方未在该期间回复不视为验收通过；双方应尽快核验并书面确认。

## 条款三：验收（谈判备选文本）
甲方未及时反馈时，乙方可书面催告并组织联合测试；仍有争议的，先支付无争议部分。该备选不得解释为甲方沉默即验收。

## 条款四：知识产权
乙方在合同订立前已拥有的通用组件列入附件《既有组件清单》。针对本项目单独开发的报表脚本、配置文件和接口文档，应向甲方提供持续使用及委托第三方维护所需的权利和材料。

## 使用说明
20%的预付款是本范本的建议文本；是否触及强制审查要求，应查询当时生效的组织审查标准。不得把本范本中的20%自动发布为所有采购合同的统一红线。
