# 临沄数研专项信息安全补充约定

文件编号：CY-LY-SEC-2026-003；状态：已签署的测试约定；生效日：2026-03-01；终止日：2026-12-31（含当日）。
双方：澄屿科技（测试组织）、临沄数研技术有限公司；合作方主体标识：MOCK-PARTY-A。
覆盖范围：双方在有效期内的数据看板技术服务项目；部门：信息技术部、数据运营部。

> 本文件纯属虚构，用于验证按主体限定的组织规则与来源引用。

## 1. 权限
乙方人员访问生产环境必须由甲方逐人授权，采用最小权限；账号共享被禁止。乙方不得仅凭本合同获得数据导出权限。

## 2. 事件通知
乙方发现可能影响甲方数据保密性或完整性的安全事件后，应在4小时内通知甲方指定联系人，并持续更新处置进展。通知不以确认损失已经发生为前提。

## 3. 存储与转委托
项目数据只可在经甲方书面确认的境内环境中处理。新增分包商必须事先书面报批；母公司对子公司的控制关系不替代报批。

## 4. 不适用的主体
临沄数研（华东）科技有限公司（MOCK-PARTY-A-EAST）并非本约定签约方，不自动享有或承担本约定。其他使用“临沄数研”商号的企业同样不自动适用。

## 5. 签署摘要
测试签署日2026-02-26；我方签署代表：陆遥；乙方签署代表：方程。原件中的联系人电话与邮箱不属于应向全部组织成员发布的必要摘录。
