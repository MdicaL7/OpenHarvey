# 澄屿科技采购合同审查标准 V2.0（付款与验收修订）

文件编号：CY-POL-2026-001；政策版本：V2.0；正式发布日及生效日：2026-09-29；维护人：沈宁。
替代文件：同编号V1.0。本文件是V1.0的局部修订，未列明的责任、数据、权利、争议及例外管理要求继续有效。
适用合同与部门：软件及数据技术服务采购；信息技术部、数据运营部。适用于生效后尚未签署的合同；已签合同不因本文件自动改约。

> 虚构测试政策。文件所载“正式发布”是模拟业务事实；在应用中仍须维护人核对并发布知识后，才可作为已生效知识使用。

## 1. PAY-01替代内容
预付款不得超过合同含税总价的20%；最终验收且收到合规发票后的余款支付期限不超过45个自然日。预付款高于20%或尾款期限长于45日均须履行单笔例外申请。

## 2. ACC-01补充内容
验收反馈期限由10个工作日调整为15个工作日；甲方沉默不等于验收通过。性能指标、测试方式和责任人要求继续保留。

## 3. 修订原因
近期交付延期增加了预付款敞口，采购资金安排允许适度延长尾款周期。此次调整没有降低数据保护、责任上限和定制交付物使用权要求。

## 4. 旧案例的使用
北辰CY-BC-2026-017的历史特批可用于解释历史交易背景，但不能成为星桥等新项目突破20%预付款上限的当然依据。单笔例外是否仍有效，应另查后续记录。

## 5. 历史可追溯性
保留V1.0及其当时使用记录，不把过去依据30%上限形成的回答改写为当时已经适用20%。
