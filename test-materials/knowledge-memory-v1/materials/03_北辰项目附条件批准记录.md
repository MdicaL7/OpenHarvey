# 北辰项目：付款例外决定记录

记录编号：CY-CASE-2026-017；合同编号：CY-BC-2026-017；合同版本：签署候选 V3，2026-06-18；项目：北辰；部门：信息技术部。
我方：澄屿科技（测试组织）；合作方：临沄数研技术有限公司；测试主体标识：MOCK-PARTY-A。金额：人民币480,000元（含税）。
记录性质：正式附条件批准；作出日期：2026-06-20；批准人：陈珂（测试财务负责人）；记录人：沈宁。

> 本记录及其签批为虚构测试数据，不对应任何真实授权。

## 1. 问题
供应商要求40%预付款，超出当时标准30%；我方要求最终验收并收票后60个自然日支付尾款，偏离标准30日。供应商接受尾款60日，条件是先收到较高预付款。

## 2. 决定与理由
批准本项目40%预付款和60日尾款，仅限合同CY-BC-2026-017的V3版本。理由为北辰项目需要在集中采购窗口锁定开发资源，且预付款由等额履约保函覆盖。

## 3. 生效条件
付款前取得覆盖192,000元预付款的有效保函；最终验收前完成代码托管；供应商未提供保函时，恢复不超过30%的预付款方案并重新谈判。
该批准不适用于其他项目、不自动续期，也不适用于供应商子公司。未满足条件不得标注为已获无条件批准。
