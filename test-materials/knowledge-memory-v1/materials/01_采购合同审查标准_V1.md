# 澄屿科技采购合同审查标准 V1.0

文件编号：CY-POL-2026-001；发布部门：法务与采购部；维护人：沈宁。
状态：已发布。生效日：2026-01-01；持续有效，直至正式发布的替代制度生效。
适用组织：澄屿科技（测试组织）。适用合同：软件及数据技术服务采购；适用部门：信息技术部、数据运营部。

> 测试声明：本文及所涉组织、人员、金额、合同均为虚构，仅用于软件测试，不作为真实法律或审批依据。

## 1. 使用与优先级
本标准是组织审查标准。参考范本仅供起草；单笔案例中的特批不构成通用授权。个人写作习惯不得改变风险等级或审批条件。适用部门、交易主体或合同类型不明确时，应先列明待确认事项。

## 2. 付款 [PAY-01]
预付款不得超过合同含税总价的30%。余款应在最终验收通过且收到合规发票后30个自然日内支付。若合同约定60日或更长付款期限，列为付款偏离，要求说明资金安排及相应审批。
付款必须同时绑定明确的交付里程碑；仅写“甲方确认后付款”不充分。

## 3. 验收 [ACC-01]
各阶段交付物、性能指标、测试方式和验收责任人应写入附件。甲方收到完整材料后10个工作日内提出书面异议；未回复不自动视为验收通过。缺陷修复后应重新提交验收。

## 4. 责任与数据 [LIAB-01 / DATA-01]
一般违约责任上限不得低于合同含税总价的100%。故意或重大过失、保密义务违反及未经授权泄露个人信息，不适用一般责任上限。
供应商未经甲方事先书面同意不得向分包商开放生产数据；测试应使用脱敏或模拟数据。合作结束后10个工作日内删除或返还数据，并出具书面说明。

## 5. 权利与争议 [IP-01 / DIS-01]
供应商既有通用平台归其所有；甲方付费定制且单独列明的交付物，其约定权利须足以支持甲方持续使用、维护和迁移。
争议解决优先采用甲方住所地有管辖权的人民法院。其他地点须单独说明成本并履行例外申请。

## 6. 例外管理
偏离须记录问题、决定、理由、条件、批准人及对应合同版本。仅“法务审查完成”或“业务同意推进”不代表正式批准。批准条件未满足时不得描述为无条件通过。
