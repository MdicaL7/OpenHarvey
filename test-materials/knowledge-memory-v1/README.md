# OpenHarvey Memory / 知识管理网页测试包

15份关联的虚构业务文件 + 可复制提示词 + 验收清单。基准日期2026-09-29，所有公司、姓名、批准记录、金额与联系方式均为虚构。业务数字为测试设定，不是法律建议。

## 推荐第一轮顺序

1. 知识中心导入 `materials/01_采购合同审查标准_V1.md`，选择提取规则。检查上传后尚未生效；运行整理后检查候选；维护人确认后发布。
2. 导入 `02_技术服务采购参考条款_V1.md`，选择参考范本。导入 `04_合作方专项补充约定.md` 作为规则，仅关联主体A。
3. 用 `05_星桥采购合同_待审V1.txt` 新建合同空间，填写主体、部门、项目和合同类型，进行审查。检查40%预付款、60日尾款、默认验收、72小时事件通知等问题。
4. 发送“请记住，以后给我合同建议时先给结论，再给理由”。先不确认观察待确认状态，再确认并新开对话验证。
5. 将 `06_星桥审查与谈判阶段记录.md` 添加到合同资料，点击“本阶段完成”，选择审查阶段。候选应只描述审查与处置，不虚构正式批准。
6. 导入 `07_采购合同审查标准_V2及变更说明.md`，先保持修改待确认，核对V1仍有效；确认后新轮次使用V2，未改动的规则保留。
7. 用 `15_星桥采购合同_谈判V2.md` 明确指定新一轮审查对象。按页面能力替换主合同或新建空间，不假定同编号附件会自动替换主合同。新稿仍有30%预付款及20工作日数据清理两项明确偏离。

真实AI整理会调用你配置的模型，可能产生费用。本包仅生成本地文件，未调用模型、未上传资料，也未修改任何账号、记忆或数据库。

## 账号与角色

建议使用专用测试账号：管理员、独立知识维护人、普通组织成员、未加入组织的注册账号、另一个个人账号。管理员明确授予成员资格；知识维护人不同时赋予平台管理权。以上是测试前置条件，不是本包已经创建的账号。

个人Memory测试从聊天发送提示词，不能用批量导入偏好替代“AI提出—本人确认”的路径。请只在虚构空间里测试停用、撤权或来源清理。
